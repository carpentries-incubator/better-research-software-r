## Git in this Lesson

We recommend showcasing both git in the terminal and the git tab in RStudio in this lesson.
The lesson is written to use git in the terminal, but we recommend starting with git in the terminal the first day and then showcasing the git tab in RStudio on the 2nd day.
After that, it can be up to the instructor if they want to use terminal or the git pane.
